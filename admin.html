How to publish on GitHub
  1. Click Download file — save the .html file to your computer
  2. Go to your GitHub repository: the website repository on GitHub
  3. Click Add file → Upload files
  4. Drag the downloaded file and click Commit changes
  5. Add the post to the list in writing.html and, if it is the newest, index.html
  6. Done — your post is live in ~1 minute!
